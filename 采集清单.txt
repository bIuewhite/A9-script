============================================
狂野飙车9 脚本 —— 采集清单
============================================

【第 0 步：装环境】双击「一键配置.bat」
  会自动找 Python、装依赖、跑一遍环境体检，并告诉你还差什么。
  装完随时可以用 python main.py check 再查一遍。

【第一步：采集按钮模板 / 界面标志】双击「采集模板.bat」
  单窗口操作：
    d = 下一个模板        a = 上一个模板
    Enter 或 s = 保存框选   n = 刷新截图
    r = 重新框选          q = 退出
  做法：先切到对应界面 → 按 n 刷新 → 拖框框住目标 → 回车保存。

  ※ 工具里会显示每个模板的编号，以工具显示的为准（下面按界面顺序排列）：

  ┌────────────────────┬──────────────────────────────┬────────────────────┐
  │ 模板名              │ 在哪个界面 / 框什么            │ 必采               │
  ├────────────────────┼──────────────────────────────┼────────────────────┤
  │ mode_entry         │ 主界面：框「开始」按钮          │ 是                 │
  │ car_list           │ 选车界面：框左上角「车辆选择」标题│ 是（界面识别用）    │
  │ mode_card          │ 模式选择界面：框「经典系列赛」卡片│ 是（界面识别用）    │
  │ detail_start       │ 详情页：框「开始」按钮          │ 是                 │
  │ detail_skip        │ 详情页(没油)：框「跳过」        │ 是                 │
  │ detail_back        │ 详情页：框「返回」按钮          │ 是                 │
  │ match_error        │ 匹配错误弹窗：框「标题栏+右上角×」│ 有弹窗就采        │
  │ dynamic_reward     │ 框左上角「动态奖励」标题（别框卡片）│ 是（选奖励用）    │
  │ continue1          │ 赛后：框第一个「继续」按钮      │ 是                 │
  │ continue2          │ 赛后：框第二个「继续」按钮      │ 是                 │
  │ missed_opportunity │ 框「错失机会」按钮              │ 是                 │
  │ milestone          │ 里程碑弹窗：框标志              │ 是                 │
  │ milestone_continue │ 里程碑弹窗：框「继续」          │ 是                 │
  │ rank_up            │ 升段弹窗：框标志                │ 出现就采           │
  │ rank_up_continue   │ 升段弹窗：框确认按钮            │ 同上               │
  │ rank_down          │ 降段弹窗：框标志                │ 出现就采           │
  │ rank_down_continue │ 降段弹窗：框确认按钮            │ 同上               │
  └────────────────────┴──────────────────────────────┴────────────────────┘

  注意：
    - 框选只框按钮文字/图案本身，别框整条按钮底色，也别带背景。
    - match_error 要框「标题栏 + 右上角 ×」一整条，脚本靠它算 × 的位置
      （见 config.py 的 MATCH_ERROR_X_OFFSET / Y_OFFSET）。
    - dynamic_reward 只框左上角那四个字「动态奖励」。卡片图案每次都换，
      千万别把卡片框进去，否则换一批奖励就认不出来了。
    - 采完用 python main.py test <模板名> 验证匹配置信度和位置。

【第二步：采集车辆车卡】双击「采集车辆.bat」
  - 到【选车界面】，框选每一辆车的车卡。
  - 按顺序采：car_1 = 主车，car_2 = 第一备用车，car_3 = 第二备用车……
  - 没油时脚本会自动按这个顺序换下一台备用车。
  - 建议【整车卡一起框】（车 + 右边的图纸海报），高度和宽度尽量统一：
    这样每辆车的模板尺寸一致，匹配位置就是卡片中心，点它最稳。
  - 车辆数量不同，就改 config.py 里的 CAR_TEMPLATES 列表（增删 car_N），
    也可以直接在控制台的「选车管理」页面增删和调顺序（还支持「截图选车」当场框）。

【第三步：开始运行】双击「启动控制台.bat」打开图形界面（或「运行脚本.bat」用命令行），
  Ctrl+C 停止。不用管游戏现在停在哪一屏：脚本会先认界面，从当前这一屏接着跑。

氮气已按坐标（NITRO_X=1624, NITRO_Y=809）双击，无需采集。
前提：游戏内已开启自动驾驶(TouchDrive)。
